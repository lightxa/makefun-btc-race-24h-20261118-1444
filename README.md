A cbBTC trading bot that races one-minute on-chain prices with $1,000 of paper money: it buys genuine trend-leg breakouts (top of the trailing 240-bar range with 60-bar and 30-bar momentum behind them) and, on days with no leg, healthy dips above the 240-bar average, with hard stops on every trade and a cooldown after every exit so it never re-buys the top of the leg it just sold.

## Run it

```sh
python3 main.py
```
